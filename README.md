# skills

Personal skill collection installable one skill at a time.

## Plugins

| Skill | Description |
| --- | --- |
| [cytation-bca-562](plugins/cytation-bca-562/skills/cytation-bca-562/SKILL.md) | Parse Cytation 562-nm BCA Excel files into [1-page consolidated PDF reports](docs/examples/cytation-bca-562/example.pdf). |
| [suggestcommit](plugins/suggestcommit/skills/suggestcommit/SKILL.md) | Suggests five Conventional Commits messages for the current git changes and commits the selected one. |
| [microscopy-softwares-and-formats](plugins/microscopy-softwares-and-formats/skills/microscopy-softwares-and-formats/SKILL.md) | Diagnose, stitch, and quantify Fiji/ImageJ and EVOS M7000 microscopy datasets. |
| [labs-of-interest-discovery](plugins/labs-of-interest-discovery/skills/labs-of-interest-discovery/SKILL.md) | Discover disease-relevant wet-and-dry labs from recent PubMed papers at predefined institutes. |
| [labs-of-interest-evaluate](plugins/labs-of-interest-evaluate/skills/labs-of-interest-evaluate/SKILL.md) | Assess a lab in a two-column PDF with methods and alumni outcomes. |
